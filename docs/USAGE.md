# Using Flow

## Server selection and search

Open the link button and enter a directory URL. Select **Use as my media server**
to save it as the default. HTTP/HTTPS directory indexes and anonymous FTP
listings in Unix or DOS format are supported. A direct media file URL can be
opened without selecting the server checkbox.

**For you** searches the full reachable catalog. Select a category such as Hindi,
English or TV series to search that collection and its subfolders. Explore
search uses its current folder. A selected collection receives scan priority.
Read the completion status before treating an absent title as unavailable.

Search suggestions combine known server titles with public movie names. The
availability label refers to the active collection. Choosing a suggestion closes
the panel and focuses results on the title and related names.

## Recommendations and watched titles

The feed mixes two recent releases with one older favourite when both groups
are available. Recent means the current or previous calendar year. Ratings are
shown only when supplied by the online chart source. Curated Flow picks are
used when charts are unavailable.

See more appends another batch. Existing cards stay in position during indexing.
Use the check button or Mark as watched to hide a title from recommendations.
Watched titles remain searchable. Watchlist includes a Show watched titles
switch, and Include watched in recommendations restores them to the feed.

## On-device media

Grant Android video/audio access to show indexed shared media grouped into
folders. The scan excludes app-data/cache paths, files below 256 KB and clips
shorter than 30 seconds to reduce game assets. Add a folder or open a file
manually to access media omitted by those filters or not indexed by Android.

## Playback

Tap fullscreen to enter landscape. Back exits fullscreen before leaving the
player. Pinch to zoom between 50% and 400%. Selecting a picture-size preset
resets zoom. Vertical swipes on the left change screen brightness and on the
right change media volume. The options menu contains audio/subtitle selection,
decoder mode, display controls, bookmarks, chapters and a sleep timer.

If Auto mode cannot play a supported file, try Software mode. Unreachable
sources, damaged files, unsupported profiles and revoked file grants can also
prevent playback.
